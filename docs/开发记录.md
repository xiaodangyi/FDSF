样例不等于独立测试集，首次调用耗时不等于稳定帧率。跨类别抑制降低重复计数，但不能修复错误分类，也可能压掉高度重叠的不同物体。新增五类未训练，尚未完成八类验收。

### 讲解提纲

- YOLO 先在内部缩放图上预测，再还原为原图框；显示面板不改变坐标。
- 分数阈值像筛选门槛，门槛升高可能同时减少误报、增加漏报。
- 重复框抑制像核对名册，同一物品不能换个类别再数一次。
- JSON 是后续分割和对比模块共用的结构化记录；成功执行不等于识别正确。

完成推送后停在此阶段；下一步为八类数据集准备。

### 学习提纲

- 训练集像练习题，验证集像阶段测验，测试集像最后才打开的独立考试；相同作者或相同照片不能两边都出现。
- 框标签是模型的标准答案。把异常热区或一个“整堆物品”框当成逐件答案，会教错计数规则。
- 数据够不够不只看总张数，还要看每类实例、拍摄环境、物体大小以及测试组是否代表真实使用场景。
- `Epoch` 是把训练图像完整过一遍；loss 衡量训练误差，验证指标用于观察模型对未参与训练图片的表现。三轮试跑只证明训练链路可用，不证明准确。
