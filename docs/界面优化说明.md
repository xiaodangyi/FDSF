# 识别工作台界面优化

使用 ui-ux-pro-max 的 Minimalism & Swiss Style、蓝色中性色板和 Comparative Dashboard 建议，结合本项目的 Gradio 5.49.1 实现。设计系统检索附带的 Hero + Features 营销页结构不适用于操作工具，没有采用；本机无 Gradio 专用栈数据，按实际组件接口实现。高级设置折叠未找到直接匹配的检索规则，依据技能内置 Forms & Feedback 默认建议保留渐进展示。

界面结构：左侧原图与运行控制，右侧概览、检测/清单、数量对比和详细报告。默认只保留上传和运行操作，支持载入已有杯瓶验证图。识别前按钮禁用，运行中显示状态并禁用重复操作，成功/失败除颜色外同时用文字标明。

概览里的“件数”是模型输出数量，不是人工真值；“差异类别”只对两路成功且原图指纹一致的结果计算。失败、未运行、类别不支持均不伪造为零。结果失效、原图隔离、推理与导出仍复用原逻辑。没有改变训练权重、提示词、识别参数和固定实验记录。

新版独立放在 `deskvision/web/`，避免修改第八阶段协议已冻结的 `deskvision/ui.py`。启动：

```powershell
. .\environment\activate-ai-cuda.ps1
```

```powershell
python -m deskvision.web
```

若7860已在运行旧版本，新版可用 `python -m deskvision.web --port 7861`。旧版本保留 `python -m deskvision.ui`。新版启动时将 TEMP、TMP 指定到项目 `.local/web-temp/`，Gradio公开预览缓存放在 `runs/web-cache/`，避免与私有配置目录的访问保护冲突；下载时仍需在浏览器选择E盘目标目录。

无新前端依赖、无外部字体请求，使用系统中文字体；浅色/深色均提供颜色变量，支持窄屏堆叠、键盘焦点和减少动态效果偏好。
