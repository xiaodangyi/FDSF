## 明确隔离的来源

取得 `quailrobot/fasteners-v1-sample` 的 300 张合成候选，抽查联系表中的 9 张后发现螺纹和物体形态不真实，整批标记为隔离，不进入数据版本。其 CC BY-NC-SA 4.0 许可及固定版本保留在来源配置中。来源许可允许使用不等于视觉标签适合训练。

其他搜索过但未采用的来源包括需要密钥才能取数或许可不清的 Roboflow 仓库、无 LICENSE 的 GitHub 数据、只有分类图或合成多视图的仓库，以及 MVTec 其他需要表单的数据集。没有把它们算入可用样本。

Commons 只有目录元数据，本机没有实际下载原图，未计入可用样本。下一批采集与入库顺序见 [桌面样本补充计划](桌面样本补充计划.md)。

## 复核与导出

- 标签使用项目固定类别编号与 YOLO 水平框；空标签必须单独批准，当前版本没有未确认的空标签。
- 同一 Open Images 作者整体放在同一用途组。差异哈希只能提示近似图，不能证明两张图片独立；跨用途近重复候选在复核时剔除或归组。
- `python -m deskvision.audit_data check` 校验候选文件和像素摘要、生成统计及近似图线索。
- `python -m deskvision.audit_data build --draft --name desk8-review-v4` 可生成明确不可训练的复核草稿，版本目录不覆盖。历史 `desk8-review-v3` 已生成，但批准试跑后复核配置摘要改变，不再作为当前可验收包。
- `python -m deskvision.audit_data verify-export --name desk8-train-v1` 核验当前试跑训练包。
- `python -m deskvision.audit_data build --name desk8-train-v1` 仅在复核门槛通过时导出；本轮已执行，并绑定三轮范围。
- 训练器生成的 labels 根目录 train／val／test.cache 为允许的派生缓存，未知额外文件仍拒绝。导出核验逐张检查 YOLO 标签、图像可解码性、文件哈希、路径与实际划分、目录残留及八类覆盖；并将样本集合、标签及划分重新对照当前复核记录，自报哈希一致不能绕过复核。
- LOCO 必须有绑定原图与最终标签摘要的第二轮复核；`training_ready` 为假或存在未解决项，均拒绝训练。复核配置改变后旧包失效，重新导出。
- `data/desk8-review-v3/summary.json` 记录当前草稿的类别图片数、实例数、划分和 640 输入时小框统计，不代表标签质量已验收。

每个 YOLO `Epoch` 表示训练集被完整遍历一次。进入第四阶段先用三轮小批试跑验证数据加载和反向传播；这不是用来宣布模型合格的训练结果。独立测试集在第八阶段冻结参数后首次推理评估，结果见 [实验报告](第八阶段实验报告.md)；此后不能再把这九张当作未见的新测试。

第四阶段的实际执行、指标及漏检样例见 [试跑记录](第四阶段试跑记录.md)。
