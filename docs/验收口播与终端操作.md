# 项目验收口播与操作（新版界面）

这次验收只需 **5 条必需终端命令**。一条一条复制、按回车；等当前命令完成，再输入下一条。上传、识别和结果比较都在网页完成，不必再运行本地推理命令。总时长约 5 分钟，模型等待时间另算。

## 一、展示环境并打开系统

保持使用同一个 PowerShell 窗口。

**第1条：进入项目目录**

```powershell
Set-Location -LiteralPath 'E:\新建文件夹 (9)'
```

口播：“大家好，下面演示我的桌面物品识别与清点项目。首先展示运行环境，项目保存在 E 盘。”

**第2条：启用已经准备好的环境**

```powershell
. .\environment\activate-ai-cuda.ps1
```

注意最前面有一个英文点和一个空格。看到启用提示和 Python 版本即可。

口播：“项目使用本机已有的 ai-cuda 环境，不需要现场安装。”

**第3条：检查项目依赖和资源**

```powershell
python .\environment\verify_project.py
```

等命令结束，看检查是否通过。不要在检查失败时照读成功口播。

口播：“这里检查项目依赖、八类配置、模型权重和素材路径。”

**第4条：展示显卡**

```powershell
nvidia-smi
```

在输出中找到 GPU 名称和显存信息。此前环境核对结果为 NVIDIA GeForce RTX 5070 Laptop GPU、PyTorch 2.7.1+cu128、CUDA 12.8；现场以实际输出为准。

口播：“本地检测使用 NVIDIA RTX 5070 Laptop GPU。环境检查通过后，下面进入可视化界面。”

**第5条：启动新版界面**

```powershell
python -m deskvision.web --port 7861
```

等终端出现本地网址，保持这个窗口开着，不要再往里面输入命令。如果新版页面已经打开并能正常使用，跳过这条，直接使用现有页面。新版启动器会自动把临时文件和 Gradio 缓存放到项目的 E 盘目录。

口播：“这是新版视觉工作台。它把本地检测和大模型识别放在一起，便于对同一张图片进行独立比较。”

## 二、网页演示

**第6步：打开页面**

浏览器地址栏输入 `http://127.0.0.1:7861/` 并按回车。

口播：“页面启动后，上传同一张原图，分别运行两条识别路线。”

**第7步：上传图片**

点击“载入杯瓶示例”，或者点击“上传原图文件”后选择：

`E:\新建文件夹 (9)\data\desk8-train-v1\images\val\oi_38451ec391f20ab5.jpg`

口播：“这张验证图的人工真值是一个杯子和一个瓶子。它只用于现场功能演示，不计入后面的固定测试统计。”

**第8步：运行本地 YOLO 和 SAM**

确认“使用 SAM 2 描绘实例轮廓”已勾选、权重模式为“八类微调模型”，然后点击“运行 YOLOv8 + SAM 2”，等待完成。也可以先展开“识别设置”展示置信度、IoU、输入尺寸和计算设备；演示时保持默认值即可。

口播：“本地路线先由 YOLO 判断类别和位置，再由 SAM 根据检测框生成物体轮廓。SAM 不会修正 YOLO 的类别或数量。”

**第9步：运行 DeepSeek**

点击“运行 DeepSeek”一次，等待完成。这一步会将原图发送给 DeepSeek 并产生 API 用量；不要再点击“运行两路并比较”重复调用。

口播：“第二条路线将同一张原图独立交给 DeepSeek，不会把 YOLO 结果提供给它，也不参与 YOLO 训练。”

**第10步：比较、查看并导出**

在“识别结果”标签页查看“本地检测与分割”和“独立物品清单”；再切换到“数量对比”和“详细报告”。需要留档时，在页面底部下载当前结果，并将浏览器下载位置选到 E 盘项目目录。

口播：“这里可以查看两路的图片、数量和报告。数量差异不能代替人工真值；格式合法也不代表识别结论一定正确。现场结果以实际显示为准。”

## 三、展示固定测试和总结

在 Codex 左侧文件列表或项目文件夹中打开 [第八阶段实验报告](第八阶段实验报告.md)，无需再开 PowerShell，也不需要重新跑测试或调用接口。展示报告的“计数指标与结果”和“错误样例”部分。

口播：“已有固定测试共九张图，两路都成功运行九张。YOLO 加 SAM 有七张图的八类计数全部正确，绝对计数误差总和为四；DeepSeek 在这九张图上全部计数正确。这个小样本结果不能代表所有真实场景。测试中，螺丝刀图片有物体被多检为橡皮，书也出现错类。我们没有人工像素掩膜真值，因此不声称已经测得分割准确率。”

“项目中的难点主要有两部分。YOLO方面，需要把原有类别映射到项目的八个类别，整理和复核训练图片，并处理重复框、坐标与颜色通道一致性；模型训练完成仍然会有错类。大模型方面，需要正确配置图像请求、服务参数和输出格式，还要处理失败情况。即使接口返回成功、JSON格式正确，也必须对照原图核验内容。下一步会补充复杂桌面和易混淆物品的新数据，再用独立测试集评估。”

使用提醒：新版启动器已经自动处理临时目录，不需要额外输入环境变量命令。不要打开或展示 `.local\deepseek.env`；不要重训，也不要重跑固定测试。若 `nvidia-smi` 不可用，略过第4条，以项目环境检查结果为准。

如果 7861 端口被占用，可改用：

```powershell
python -m deskvision.web --port 7862
```

然后打开 `http://127.0.0.1:7862/`。旧版 `python -m deskvision.ui` 仍可保留用于回溯，但本次演示使用新版入口。
