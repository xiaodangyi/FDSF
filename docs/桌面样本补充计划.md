# 桌面样本补充计划

当前 64 张复核草稿完成了格式与可见框检查，尚缺目标使用环境。下面是下一批收集任务，均为待办，不是已取得的数据，也不是达到某个固定张数就保证准确的标准。

| 类别 | 当前总实例 | 下一批优先内容 |
|---|---:|---|
| 杯子 | 11 | 陶瓷马克杯、透明普通杯；俯视与侧视；不同实物 |
| 瓶子 | 14 | 透明与不透明水瓶；不同容量、直立与横放；独立测试场景 |
| 书 | 7 | 书籍与装订笔记本；封面、书脊、摊开及可分辨本数的叠放 |
| 橡皮 | 8 | 不同颜色与纸套；单独和混放；排除铅笔尾和黑板擦 |
| 螺丝刀 | 14 | 不同手柄与长度；一字和十字；完整手柄与杆算一个实例 |
| 螺丝 | 40 | 取出透明袋放到桌面；不同尺寸、朝向、数量和金属反光 |
| 螺母 | 40 | 不同规格、正面和侧面；与螺丝、垫圈混放 |
| 垫圈 | 40 | 平垫与弹垫；亮暗背景；与螺母混放，加入相似干扰物 |

每类先补少量不同实物和拍摄会话，检查缺口后再扩充。优先覆盖木纹、浅色、深色桌面，日光与室内灯，俯视与斜视，单件、混放和适度遮挡。重点补书、橡皮、普通桌面五金以及独立测试会话。

另拍空桌面和只有干扰物的照片，例如硬币、笔、钥匙、碗、瓶盖、橡胶圈。只有逐图确认八类均不存在，才可给空标签并设置 `verified_negative`；不得把漏标图片当负样本。

## 收集与入库顺序

1. 每次拍摄建立独立会话目录，例如 `data/raw/desktop/session-001/`，保留原图，不只保存缩小截图。当前公开数据准备器尚未实现自采会话导入，取得照片后再补入口。
2. 会话记录包含拍摄人、时间、桌面、光照、物品组合、授权及用途分组。先以整个拍摄会话划分 train／val／test；近似连拍、裁剪和增强副本不跨组。
3. 按 `docs/标注规范.md` 标全八类，YOLO 编号不变；反光不等于新物体，螺丝头不额外数一件。无法判断的目标进入待复核，不略去。
4. 检查原图与框叠加图，特别核对微小五金、遮挡边界及漏标。保存图像摘要、标签摘要、会话和复核说明，再加入候选清单。
5. 重新运行统计和跨组重复检查；验证与测试要有不同会话。列清每类剩余缺口，处理后再批准训练版本。

## 交给第四阶段的验收材料

- 来源、许可、每类图片与实例统计、会话划分及负样本清单。
- 完整复核记录、框叠加检查结果、未解决项为空的依据；不能仅把布尔开关改为真。
- 独立测试会话的保留说明：试跑期间只看训练和验证结果，模型及阈值确定前不调看测试指标。

三轮训练可以检查代码链路，但不会弥补数据分布缺失。最终泛化结论需在未参与调参的真实桌面会话上验证。
