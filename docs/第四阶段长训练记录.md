## 结果的解释边界

之前三轮独立验证 mAP50 为 0.17777，不能据此判断已经收敛。此次增加优化轮数，先看模型充分拟合后的验证结果。当前图像量和真实桌面场景仍少，多轮训练不能创造场景多样性；即使验证分数明显提高，也不能直接宣称八类桌面清点可靠。
