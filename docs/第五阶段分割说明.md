# 第五阶段：YOLOv8 检测后接 SAM 2

2026-10-23 完成业务串联。第四阶段长训练的验证 mAP50 为 0.98469、mAP50–95 为 0.82935，默认阈值下 13 张验证图中 8 张八类计数完全正确，足以继续验证分割接口，但不能据此宣布真实桌面识别合格。独立测试组仍保留。

## 运行

复用 ai-cuda、本地八类最佳权重和 SAM 2.1 Hiera tiny，不训练、不下载、不新增依赖。在项目根目录运行：

```powershell
. .\environment\activate-ai-cuda.ps1
python -m deskvision --mode finetuned --weights runs/train/desk8-full-20261023-204546/weights/best.pt --image data/desk8-train-v1/images/val/loco_val_000.png --segment --device cuda:0
```

换成自己的图片即可。`--sam2-weights` 可以显式选择本地 tiny 权重，否则读取忽略的 `.local/config.json` 中的 `sam2_weights`。不加 `--segment` 保持原来的检测用法；COCO 基线也能接分割，但只支持原有三类。

每次在 `runs/segmentation/` 下建立独立目录：

| 文件 | 含义 |
|---|---|
| `annotated.png` | YOLO 检测框、类别、检测分数和计数 |
| `segmented.png` | 原图叠加掩膜、轮廓和检测框，右侧显示分类计数 |
| `result.json` | 原始检测及分割实例、参数、哈希、版本、耗时和状态 |
| `masks/instance-0001.png` | 单实例原尺寸灰度掩膜，0 为背景、255 为前景 |
| `masks/instance-0001-contours.json` | 原图像素轮廓和父轮廓索引，保留孔洞层级 |

大文件和图片保留本机，不提交 Git。检查摘要保存在 [第五阶段检查报告](../reports/stage5-segmentation-checks.json)。

## 接口与计数规则

`Sam2Segmenter.segment(image_bgr, report, destination)` 接收原图和检测报告，返回新报告。输入尺寸必须与检测记录一致；拒绝重复实例编号、无效或越界框。OpenCV 的 BGR 原图仅在送入 SAM 2 前转成 RGB，不用可视化画布做模型输入。

YOLO 的框已还原到原图像素 `xyxy`。SAM 2 的 `normalize_coords=True` 在内部处理坐标转换，调用端不再手动缩放或归一化。每图编码一次，再逐框解码，设置 `multimask_output=False`；每个结果必须是原图高宽的二值掩膜。

检测实例与分割实例通过 `instance_id` 对应。类别、检测分数、数量和原检测框保持不变；SAM 2 只描边，不重分类。掩膜可以超出提示框，也可以互相重叠，每个实例独立保存。像素面积直接数前景像素，掩膜包围框右下角为开区间；轮廓多边形用于展示，不用多边形面积代替像素面积。

`detection_confidence` 与 `sam2_predicted_iou` 分开记录。后者是模型对掩膜质量的预测，并非实测 IoU 或校准后的准确率，不与检测分数相乘，也不据此改动数量。

通俗地说，YOLO 负责“找到物品、贴名字、数件数”，SAM 2 负责“沿着已找到的物品描边”。名字贴错、少找到一个物品，描边步骤不会自动纠正。

## 空结果与失败

- 无检测：记录 `skipped_no_detections`，不加载 SAM 2、不建立掩膜目录，正常输出零检测报告与图片。这不表示证明原图没有物品。
- 有框但掩膜全空：记录该实例 `empty`、面积 0、包围框与重心为空，保存全零掩膜，检测数量不减；界面显示空掩膜数。
- 缺失权重、模型失败、异常尺寸或非有限输出：命令返回 1。输出目录已经建立时，写入 `status=failed`、错误阶段及原因，并保留检测与已有部分文件；部分产物不能当成功结果。输入阶段尚未建立目录的失败只输出终端错误。
- 每张图结束或解码失败时清理图像特征，避免下一张复用旧特征。

## 实际验证与限制

| 检查 | 结果 |
|---|---|
| LOCO 验证图 `loco_val_000` | 1600×1100，螺丝、螺母、垫圈各 2，生成 6 个非空原尺寸掩膜；肉眼检查轮廓基本贴合，螺母与垫圈孔洞保留 |
| 杯瓶验证图 `oi_38451ec391f20ab5` | 生成 2 个非空掩膜；杯子仍误标成瓶子，沿用 YOLO 的“两只瓶子”，未把分割成功当分类正确；透明杯边缘及上方存在少量碎点，不能声称轮廓完全准确 |
| 人工生成纯灰图 | 0 检测，跳过 SAM 2，加载及分割计时为 0；只验证程序空分支，不作为真实负样本准确率 |
| 缺失 SAM 权重 | 明确失败、返回 1，检测结果保留，无伪造成功分割图 |
| 单元检查 | RGB 转换、原图框、实例关联、空掩膜、不改计数、孔洞、非法输出、异常后重用及命令行失败；连同原有检查共 29 项通过 |

前两张使用验证图，不使用独立测试图。没有人工逐像素真值，不报告分割准确率。检测训练集仅 42 张，五金场景单一，仍有错类、多检和真实桌面泛化风险。

已有环境未编译可选 CUDA 后处理，调用固定 `apply_postprocessing=False`，不启用填孔或碎点去除。RTX 5070 上分割使用 BF16 自动混合精度，其他情况使用 FP32。首张五金图 SAM 2 加载约 1131 ms、编码约 345 ms、6 框解码合计约 233 ms、掩膜与轮廓写盘约 122 ms；记录包含冷启动，不能推导稳定帧率。

源码自主编写，模型接口使用 [SAM 2 官方实现](https://github.com/facebookresearch/sam2)，检测后接框提示的思路参考 [Grounded-SAM-2](https://github.com/IDEA-Research/Grounded-SAM-2)。固定环境提交与权重来源见 [环境说明](../environment/README.md)。
