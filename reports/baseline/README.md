# 第二阶段基线运行记录

这些 JSON 是 2026-10-23 在现有 ai-cuda 上真实运行后复制的记录，不是手工编写的预测或八类效果评估。原图、中文标注图和逐次运行文件留在本机 runs/baseline。这里记录的 artifacts 是原运行目录中的文件名，本目录不包含对应图片。

| 文件 | 输入及用途 | 结果 |
|---|---|---|
| baseline_000000000127.json | 已有 COCO128 的 000000000127.jpg，功能检查 | 杯子 1、书 1 |
| before_nms_000000000142.json | 已有 COCO128 的 000000000142.jpg，修正前历史记录 | 瓶子 2、杯子 1，同一罐子跨类别重复计数 |
| baseline_000000000142.json | 同图启用跨类别抑制后的记录 | 瓶子 2、杯子 0，仍有牛奶盒误识别 |
| baseline_blank_cpu.json | 本地生成的 640×480 纯白 PNG，CPU 空结果检查 | 支持的三类为 0，未训练的五类为 null |

修正前文件缺少 class_agnostic_nms 参数，使用当时默认的同类抑制；其余最终基线显式记录为 true。历史记录保留原样，不补写为当时未产生的字段。

公开数据说明：[COCO128 官方介绍](https://docs.ultralytics.com/datasets/detect/coco128/)。样例可能在预训练中出现，不视为独立未见测试，也不能直接推出准确率。图片许可与项目标注边界还需第三阶段核对，故本阶段不复制原图入库。纯白图由 NumPy 生成，仅检查空结果行为。

输入、权重和最终类别配置的 SHA256、运行参数、库版本都在记录中。耗时是逐次单张调用，包含首张初始化与预热，不能拿 GPU 样例与 CPU 空白图的耗时直接比较设备性能。

八类范围、原图坐标语义和运行方式见 [基线使用说明](../../docs/基线使用说明.md)。
