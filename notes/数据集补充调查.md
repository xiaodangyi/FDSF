# 八类桌面数据补充调查

调查日期：2026-10-23。只把实际下载、查看与标注完成情况计入进度。本次使用 research 技能的一手来源及引用记录要求；遵循既定用户偏好，未启动子代理。

## 已实际取得的候选

### Open Images

依据[官方下载页](https://storage.googleapis.com/openimages/web/download_v7.html)下载验证集[检测框 CSV](https://storage.googleapis.com/openimages/v5/validation-annotations-bbox.csv)与[图片元数据 CSV](https://storage.googleapis.com/openimages/2018_04/validation/validation-images-with-rotation.csv)，分别为 25,105,048 和 15,245,485 字节，原文件及 URL／SHA-256 侧录在 `data/raw/openimages-supplement/`。

按八类映射、逐图 CC BY 2.0 声明、零旋转、无所选类别组框字段筛选后，实际下载 **25 张**书或螺丝刀候选。元数据和原始框保存于 `selected.json`，三张框叠加联系表已查看。部分书架图片虽然源字段未标组框，实际仍把多本书圈为一个框，因此**不能仅按 CSV 标志批准训练**。另有螺丝刀框只含手柄，需要修正；本批尚未完成逐图八类检查与补标，进入训练数为 0。

后续统一使用原准备器的作者 URL 哈希规则分组，与已有来源一起做文件、像素及作者隔离，保留源 validation 标识。当前采样清单只是调查材料，不作为新的训练 manifest；公开源也不当作完全未见的最终测试证据。

## 有价值但暂缓的来源

### MVTec Screws

[官方页面](https://www.mvtec.com/research-teaching/datasets/mvtec-screws)说明该集有 384 张木质背景照片、13 种螺丝和螺母、4,426 个有向框，采用 CC BY-NC-SA 4.0。这是 MVTec Screws，不能与 MVTec AD 的 screw 异常分类图片混淆。官方获取使用个人信息表单；本次未提交表单，也未取得图像。没有证据表明它包含垫圈。若取得数据，需要转换水平可见框并复核实例定义。

### ScrewCount：许可描述冲突，修正之前判断

[作者仓库](https://github.com/industoai/ScrewCount)链接到[作者数据集固定版本](https://huggingface.co/datasets/industoai/ScrewCount/tree/f8e2d87b440be185c02d1544085f004707fe4e61)。该版本数据卡 YAML 写 `cc-by-nc-nd-4.0`，但 LICENSE 文件及正文写 CC BY-NC 4.0，因此不能简单地认定许可已统一核实。此前进度消息只提 CC BY-NC 4.0 不够完整，在这里明确修正。

此外，它主要提供计数点与密度图，示例框不是所有实例的检测框；不能直接变成完整 YOLO 检测标签。本次未下载图片，未纳入训练。原始 GitHub/Hugging Face API 快照在 `data/raw/supplement-research/`。
