# 八类桌面物品数据来源初查

核查日期：2026-10-23。只读取官方说明与类别表，未下载正式图片、未统计可用样本，不代表数据已备齐。获取时需记录版本、来源和许可。

## COCO：杯子、瓶子和书

[Ultralytics 固定版本配置](https://github.com/ultralytics/ultralytics/blob/v8.3.203/ultralytics/cfg/datasets/coco.yaml) 中 bottle=39、cup=41、book=73。这是 Ultralytics 连续编号，不是 COCO 原始 JSON category_id。项目另定瓶子=1、杯子=0、书=2，不混用。

先筛选所需图片并复用本机资源，不默认下载约 20GB 全量包。公开预训练数据不视为完全未见的最终测试证据。获取时核对 [官方入口](https://cocodataset.org/#download) 和 [使用条款](https://cocodataset.org/#termsofuse)，落实图片及标注的许可、署名。本次条款页面使用前端加载，没有据此宣称所有条款已核实。

## Open Images：橡皮、螺丝刀等候选

[官方检测类别表](https://storage.googleapis.com/openimages/v5/class-descriptions-boxable.csv) 中已核实：

| 原始标识 | 类别 | 项目候选映射 |
|---|---|---|
| /m/01bms0 | Screwdriver | 螺丝刀 |
| /m/02fh7f | Eraser | 橡皮 |
| /m/02jvh9 | Mug | 杯子 |
| /m/02p5f1q | Coffee cup | 杯子，需避免与上项重复 |
| /m/04dr76w | Bottle | 瓶子 |
| /m/0bt_c3 | Book | 书，核对装订笔记本范围 |

类别存在不证明数量、可下载性、框质量和分布合格。此表未检出精确名称 Screw、Nut、Washer，不能声称覆盖五金三类，也不推断其他标注体系没有相关目标。

[官方镜像说明](https://github.com/cvdfoundation/open-images-dataset) 介绍检测图片下载，体量很大，第 3 阶段按图片 ID 筛选，不全量同步。保留来源许可，处理层级类别、群组框和未完备标注，不能改一行编号后直接混训。详见 [官方页面](https://storage.googleapis.com/openimages/web/index.html)。

## 五金三类：尚未选定合格来源

后续联网及 GitHub 搜索螺丝、螺母、垫圈检测数据，核对类别、实例框、多物品场景、授权、下载与近重复。只有分类图片的源还需补框；来源不清或只有演示的仓库不算可用数据。缺口需明确记录，再补拍补标。

[MVTec LOCO AD 官方说明](https://www.mvtec.com/research-teaching/datasets/mvtec-loco-ad) 表明用途是无监督异常定位，真值针对异常区域，许可 CC BY-NC-SA 4.0，下载含表单。即使有五金场景，也不等于具有三类逐实例检测框，暂不作为直接训练源。

## 第 3 阶段交付门槛

每类列明图片量、实例量、划分、来源和复核状态。转换留记录，缺类不伪装成已覆盖。独立自采测试图不用于调参；辅助标注需人工核对，不能直接把预测当评测真值。

## 第 3 阶段实际结果补记（2026-10-23）

上面的初查是当时的计划，不代表最终状态。之后实际获取并校验 Open Images 234 张候选、合成五金 300 张、MVTec LOCO 透明袋五金 20 张。本轮增加瓶子复核后，草稿采用 44 张 Open Images 照片和 20 张 LOCO 照片；20 张 LOCO 的 120 个五金框已重画并检查叠加图，数据仍待补充桌面场景。合成五金只抽看联系表 9 张，因物体形态不真实隔离整批，没有计入数据集。详细类别统计、署名与限制见 [数据准备说明](../docs/数据准备说明.md)。

LOCO 在这里仅提供真实五金照片，异常区域掩膜没有当作实例框。其 CC BY-NC-SA 4.0 许可、固定场景与不适合作最终桌面测试等限制均需继续保留。
